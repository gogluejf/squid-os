Objective: Add centered squid pixel art in viewport when no user messages yet

State Analysis

Current State
  • When a new session starts, the viewport shows only system/internal messages rendered as collapsed boxes
  • No visual welcome element — the viewport area below init messages is empty until the user sends a message
  • `updateViewportContent()` renders init messages but nothing else when no user messages exist
Desired State
  • When there are no user messages in the session, display a centered squid pixel art in the viewport
  • The art uses 1=filled, 0=empty on a 24x14 grid, rendered with lipgloss blocks
  • When the first user message is sent, the pixel art disappears — normal messages take over
  • The art is vertically centered in the viewport area above the textarea
Gap Analysis
  • Need a `squidArt` function to render the pixel art as styled blocks
  • Need to detect "no user messages" state in `updateViewportContent()`
  • Need to vertically center the art within the viewport height
  • Need a style for the squid fill color that fits the existing palette
