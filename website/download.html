Get Squid OS

Built for Linux, macOS, and Windows.

Quick install

Clone the repository and run the installer:

# clone and install
$ git clone https://github.com/gogluejf/squid-os
$ cd squid-os
$ ./install.sh

Build manually

Squid OS is a single Go binary — building from source is just as simple:

# requires Go
$ go build
$ ./squid-os

Next steps

The README covers configuration, providers, and every feature in detail. Point Squid OS at your local Ollama, vLLM, or LiteLLM endpoint — or connect a cloud provider — and start talking to your operating system.

One conversational interface for your entire operating system. Built in Go, optimized for local AI.
