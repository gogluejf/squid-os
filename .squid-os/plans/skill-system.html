🐙 Squid-OS Skill System

Implementation Plan — v1.0 · Generated from skill.plan ·

1. Goal

Add a Skill System to squid-os — a lazy-loaded, self-describing knowledge layer that sits above the existing tool registry. Skills provide instructions, conventions, and assets for domain-specific tasks. They are discovered, loaded, and rendered with visual distinction from core tools.

2. Conceptual Model

2.1 What Is a Skill?

A skill is a self-contained directory containing a SKILL.md file (with YAML frontmatter + instructions), optional scripts, references, and assets. Skills are lazy-loaded — only the frontmatter is in context by default; the full body loads on demand.

3.2 SKILL.md Format (per agentskills.io spec)

---
name: docx
description: >-
  Create, edit, and manipulate Word (.docx) documents. Covers tables,
  headings, page numbers, letterheads, tracked changes, and find/replace.
  Use when the user mentions Word, DOCX, or document formatting.
version: "1.0"
license: MIT
allowed-tools:
  - read_file
  - write_file
  - bash
---

# Overview
This skill handles Word document operations using python-docx.

# Instructions
1. Start from the base template at assets/template.docx
2. Load the document using python-docx
3. Apply requested modifications
4. Save to the user-specified output path

# Rules
- Always use the template — do not hardcode fonts
- Page numbers require section header configuration
- Never silently truncate content

# Output Format
Modified .docx file at the requested output path.

# Examples
**Input:** "Add a table of contents to my report.docx"
**Output:** Calls scripts/generate.py with the TOC option

# References
- `scripts/generate.py` — python-docx operations
- `assets/template.docx` — base template

4. Data Model

4.1 Skill Struct NEW

package skills

// Skill represents a loaded skill with its metadata and instructions.
type Skill struct {
    Name        string            // skill name (must match folder name)
    Description string            // from frontmatter
    Version     string            // from frontmatter (optional)
    License     string            // from frontmatter (optional)
    AllowedTools []string         // from frontmatter (optional)
    Metadata    map[string]string // from frontmatter (optional)
    
    // Content
    Body        string            // full SKILL.md body (instructions)
    Path        string            // absolute path to SKILL.md
    ScriptsDir  string            // path to scripts/ (empty if none)
    AssetsDir   string            // path to assets/ (empty if none)
    RefsDir     string            // path to references/ (empty if none)
}

// Frontmatter is the parsed YAML header of SKILL.md
type Frontmatter struct {
    Name         string            `yaml:"name"`
    Description  string            `yaml:"description"`
    Version      string            `yaml:"version"`
    License      string            `yaml:"license"`
    Compatibility string            `yaml:"compatibility"`
    Metadata     map[string]string  `yaml:"metadata"`
    AllowedTools []string           `yaml:"allowed-tools"`
}

// SkillEntry is the lightweight registry entry (frontmatter only)
type SkillEntry struct {
    Name        string
    Description string
    Path        string
}

4.2 Style Helper NEW

package ui

// StyleLabel is a helper for attaching visual style info to tools/skills.
// It carries the label text and any params for rendering.
type StyleLabel struct {
    Label string    // e.g. "skill" or "tool"
    Color string    // lipgloss color, e.g. "178" (yellow) or "110" (cyan)
    Param string    // display param field name (inherited from tool)
}

// SkillStyle returns the style label for a skill tool call.
func SkillStyle() StyleLabel {
    return StyleLabel{
        Label: "skill",
        Color: "178",  // yellow
        Param: "",
    }
}

// ToolStyle returns the style label for a core tool call.
func ToolStyle() StyleLabel {
    return StyleLabel{
        Label: "tool",
        Color: "110",  // cyan/blue
        Param: "",     // filled per-tool at render time
    }
}

5. Core Functions

5.1 skill_load(name) SKILL

Load the full SKILL.md content for the named skill and inject it into the user context. Returns the skill's instructions to the user.

ParameterTypeDescription
namestringSkill name (must exist in registry)

Logic:

  • Lookup name in skill registry
  • Read SKILL.md at the stored path
  • Extract frontmatter + body
  • Return full body text to user as an internal/system message
  • Track that this skill is "active" in the current session
func (r *Registry) Load(name string) (*Skill, error) {
    entry, ok := r.index[name]
    if !ok {
        return nil, fmt.Errorf("skill %q not found", name)
    }
    
    data, err := os.ReadFile(entry.Path)
    if err != nil {
        return nil, fmt.Errorf("read skill %q: %w", name, err)
    }
    
    return ParseSkillFile(entry.Path, data)
}

5.2 skill_list() SKILL

Return a list of all available skills with name and description. Used to build the registry injected into context.

Output: Array of {name, description} entries — lightweight, always in context.

func (r *Registry) List() []SkillEntry {
    return r.entries  // copy of all registered skills
}

5.3 skill_build(name, description, allowed_tools, overview, instructions, rules, output_format, examples, references, scripts) SKILL

Generate a new skill with the proper folder structure. Validates the contract and creates files.

ParameterTypeDescription
namestringSkill name (lowercase, hyphens only, 1-64 chars)
descriptionstringWhat it does + when to invoke (max 1024 chars)
allowed_tools[]stringOptional: list of pre-approved tools
overviewstringOne-paragraph summary
instructionsstringStep-by-step instructions
rulesstringDo/never/always constraints
output_formatstringExpected output structure
examplesstringInput/output examples
referencesstringFile paths and documentation references
scripts[]stringScript contents (name + content pairs)

Creation Contract:

  • name must match ^[a-z][a-z0-9-]*[a-z0-9]$ (1-64 chars, no leading/trailing/consecutive hyphens)
  • description must be 1-1024 chars, non-empty
  • Folder name must equal skill name
  • SKILL.md frontmatter name field must match folder name
  • Create scripts/, assets/, references/ only if content is provided
  • Skill must not already exist (unless force=true)
func (r *Registry) Build(params BuildParams) (*Skill, error) {
    // 1. Validate name
    if err := validateName(params.Name); err != nil {
        return nil, err
    }
    
    // 2. Validate description
    if len(params.Description) > 1024 || params.Description == "" {
        return nil, errors.New("description must be 1-1024 chars")
    }
    
    // 3. Check for duplicates
    if _, exists := r.index[params.Name]; exists {
        return nil, fmt.Errorf("skill %q already exists", params.Name)
    }
    
    // 4. Create folder structure
    skillDir := filepath.Join(r.baseDir, params.Name)
    if err := os.MkdirAll(skillDir, 0755); err != nil {
        return nil, err
    }
    
    // 5. Write SKILL.md
    content := buildSkillMD(params)
    skillPath := filepath.Join(skillDir, "SKILL.md")
    if err := os.WriteFile(skillPath, []byte(content), 0644); err != nil {
        return nil, err
    }
    
    // 6. Write scripts (if any)
    for _, script := range params.Scripts {
        // ...
    }
    
    // 7. Rebuild registry index
    if err := r.Rescan(); err != nil {
        return nil, err
    }
    
    // 8. Return the built skill
    return r.Load(params.Name)
}
